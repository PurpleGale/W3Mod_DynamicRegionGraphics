# Dynamic Region Graphics

A Witcher 3 Next-Gen mod that dynamically switches Ray Tracing / Path Tracing and upscaler quality (DLSS, FSR, XeSS) based on your current region, interior/exterior location, and combat status.

---

## Features

- **Per-Region Profiles:** Set Default, Ray Tracing, or Path Tracing for each region (Vizima, Kaer Morhen, Novigrad, Skellige, Toussaint, etc.).
- **Interiors & Exteriors:** Separate graphics profiles for indoor rooms and the open world.
- **Dynamic Upscaling:** Automatically adjust DLSS, FSR, or XeSS quality when RT or PT engages.
- **Disable During Combat:** Revert to your baseline settings during fights for maximum FPS.
- **In-Game Menu:** Full configuration under Options > Gameplay > Dynamic Region Graphics.
- **18 Languages:** Fully translated into all official game languages.
- **No Script Conflicts:** Zero vanilla file edits.

---

## Installation

Extract the release zip into your Witcher 3 root directory:
```
The Witcher 3/
├── bin/config/r4game/user_config_matrix/pc/modDynamicRegionGraphics.xml
└── mods/modDynamicRegionGraphics/
```
Or install via your preferred mod manager (Vortex, MO2).

---

## Compatibility

- The Witcher 3 Next-Gen (v5.00+) DX12.
- Fully compatible alongside Dynamic Path Tracing For Cutscenes.
